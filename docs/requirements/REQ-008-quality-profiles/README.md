# REQ-008：质量策略与自动选片

| 字段 | 内容 |
|---|---|
| 版本 | V1.0 |
| 状态 | 待验收 |
| 优先级 | P0 |
| 依赖 | REQ-005、REQ-006、资源评分 |
| 使用方 | REQ-001、REQ-007、REQ-010 |

## 1. 一句话定义

把用户对分辨率、来源、编码、杜比、字幕和体积的偏好保存为可复用策略，用于推荐最佳资源、自动追更和安全洗版。

## 2. 目标与非目标

目标：

- 用户不用每次手工筛选资源。
- 区分硬性条件和排序偏好。
- 给出可解释的推荐结果和落选原因。
- 支持全局、媒体库、订阅和单媒体覆盖。

非目标：

- 不仅凭文件名伪造无法确认的技术属性。
- 不把检测失败视为资源不合格。
- 不默认自动推送或自动删除旧版本。

## 3. 功能范围

| 编号 | 功能 | 优先级 |
|---|---|---|
| QLT-001 | 质量策略创建、复制和版本化 | Must |
| QLT-002 | 硬条件和软偏好 | Must |
| QLT-003 | 资源属性解析和可信度 | Must |
| QLT-004 | 可解释评分与推荐 | Must |
| QLT-005 | 策略继承和单媒体覆盖 | Must |

| QLT-007 | 策略模拟 | Must |
| QLT-008 | 内置策略模板 | Should |

## 4. 策略字段

- 分辨率：2160P、1080P、720P。
- 来源：REMUX、BluRay、WEB-DL、WEBRip、HDTV。
- 视频编码：AV1、HEVC/H.265、H.264。
- 动态范围：Dolby Vision、HDR10+、HDR10、SDR。
- 音频：Atmos、TrueHD、DTS-HD、普通多声道。
- 字幕：简中、繁中、双语、内封、外挂、无要求。
- 体积：最小、最大和偏好区间。
- 发布组和来源站点允许/拒绝列表。
- 做种数、检测状态和完整度最低要求。

每个字段可设置为：必须、偏好、排除、不参与。

## 5. 评分规则

- 硬条件不满足时不进入自动候选，但仍可在“其他资源”查看。
- 软偏好按权重计分，最终输出总分和贡献项。
- 字段未知时不得自动当作不满足，按策略选择“待确认”或低置信度候选。
- 内容检测结果优先于文件名推断；PanSou 结构化字段优先于文本猜测。
- 来源可靠性只影响排序，不直接替代媒体质量判断。
- 分数相同时优先选择已检测、较新、做种更好或来源更可靠的资源。

## 6. 策略层级

```text
系统默认 < 用户全局 < 媒体库 < 订阅 < 单媒体临时覆盖
```

界面必须展示最终生效值和来源。修改策略创建新版本，不静默改变已经提交的任务快照。

## 7. 自动升级

- 用户可设定目标质量和当前可接受质量。
- 低档资源可以先推送，后续出现目标版本时提示或生成洗版计划。
- 新资源必须严格优于当前版本，且满足最小差异阈值。
- 自动升级默认仅提示；启用后仍走 REQ-001 隔离和回滚流程。

## 8. 界面要求

- 策略编辑使用选择器、开关、优先级列表和体积范围控件。
- 资源列表显示“推荐”“满足条件”“不满足条件”和原因。
- 提供策略模拟：展示当前影片会选中哪条资源，但不创建任务。
- 提供内置模板：4K 品质优先、1080P 均衡、小体积、中文字幕优先。

## 9. 验收标准

- 硬条件、软偏好、排除项和未知字段均按规则处理。
- 同一资源和策略版本重复评分结果一致。
- 用户能看到推荐理由和落选原因。
- 策略继承和覆盖结果可解释。
- 检测失败不会被误判为资源无效。
- 自动升级只对严格胜出的版本生成动作。
- 策略模拟零副作用。

## 10. 分期建议

1. 属性模型、策略和解释评分。
2. 资源列表推荐与模拟。
3. 订阅绑定和自动选片。
4. 自动升级与洗版联动。

## 11. 待确认项与建议默认值

| 决策项 | 默认值 |
|---|---|
| 硬条件 | 无，使用均衡模板 |
| 未知字段 | 保留候选但降低置信度 |
| 自动升级 | 仅提示 |
| 体积上限 | 不设置 |
| 默认字幕 | 无要求 |
