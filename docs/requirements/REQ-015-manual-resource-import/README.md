# REQ-015：手工资源导入

| 字段 | 内容 |
|---|---|
| 版本 | V1.0 |
| 状态 | 待验收 |
| 优先级 | P1 |
| 依赖 | 现有资源模型、任务状态机、REQ-006、REQ-009 |

## 1. 一句话定义

允许用户手工粘贴磁力或 115 分享链接，经严格校验、媒体关联和预览后进入统一推送、整理和任务链路。

## 2. 目标与非目标

目标：

- 补充 PanSou 未收录的用户自有资源。
- 手工导入仍享受去重、检测、推送和审计保护。
- 支持关联 TMDB 媒体、季度和质量策略。

非目标：

- 不提供任意 URL下载器。
- 不支持 HTTP、FTP 或未知网盘链接。
- 不把原始链接返回给其他前端用户或 Agent。
- 不绕过 115 能力和幂等检查。

## 3. 功能范围

| 编号 | 功能 | 优先级 |
|---|---|---|
| IMP-001 | 磁力和 115 分享输入 | Must |
| IMP-002 | 格式、域名和密码校验 | Must |
| IMP-003 | TMDB 媒体关联 | Must |
| IMP-004 | 重复检测和预览 | Must |
| IMP-005 | 内容检测和质量摘要 | Must |
| IMP-006 | 创建标准资源与任务 | Must |
| IMP-007 | 批量导入 | Should |

## 4. 导入流程

1. 用户选择电影、剧集和可选季度。
2. 粘贴一个磁力或允许域名的 115 分享。
3. 服务端解析并验证，不信任前端类型判断。
4. 生成 canonical key，检查已导入、已推送和库内库存。
5. 磁力可选择执行 REQ-006 内容检测。
6. 展示媒体关联、类型、名称来源、重复状态和风险。
7. 用户确认后创建加密资源记录。
8. 后续通过 REQ-009 创建标准 workflow。

## 5. 安全规则

- 只接受合法 `magnet:` 和配置中的 115 分享域名。
- 不接受重定向后的未知域名。
- 提取码和链接应用层加密。
- API 响应不回显完整磁力、密码或分享链接。
- 日志只记录类型、内部资源 ID、TMDB ID和结果。
- 批量导入限制条数、请求大小和频率。
- Agent CLI 默认没有手工原始链接导入权限；如需开放使用独立 Scope。

## 6. 界面要求

- 详情页提供“手工添加资源”。
- 输入后先显示预览，不直接推送。
- 重复、无法检测、媒体不匹配和 115 能力不可用有中文提示。
- 用户可以只保存资源，或保存后立即创建推送任务。

## 7. 验收标准

- 合法磁力和允许的 115 分享可以导入。
- 未允许协议、域名、端口、用户信息和恶意 URL被拒绝。
- 重复 infohash 和分享 ID不会重复创建资源。
- 原始链接、密码和 Token 不出现在日志或响应。
- 未确认预览不会创建任务。
- 导入后使用与搜索资源相同的推送和整理链路。

## 8. 分期建议

1. 单条磁力导入和重复检测。
2. 115 分享、密码和链接验证。
3. 内容检测、质量策略和批量导入。

## 9. 待确认项与建议默认值

| 决策项 | 默认值 |
|---|---|
| 默认动作 | 仅保存，用户确认推送 |
| 批量导入 | V1 最多 20 条 |
| 磁力检测 | 可选，默认开启 |
| Agent 导入 | 默认不开放 |
