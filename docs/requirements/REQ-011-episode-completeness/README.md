# REQ-011：剧集缺集与完整度检查

| 字段 | 内容 |
|---|---|
| 版本 | V1.0 |
| 状态 | 待验收 |
| 优先级 | P1 |
| 依赖 | TMDB 季集数据、REQ-001、REQ-010 |

## 1. 一句话定义

对照 TMDB 和 115 库存，识别剧集已拥有、缺失、重复、未知和特别篇状态，指导追更、补集和整理。

## 2. 目标与非目标

目标：

- 展示每季和每集的覆盖情况。
- 识别单集、多集文件、季包、全剧和特别篇。
- 为订阅自动补集提供准确缺口。
- 区分未播出、未拥有、无法识别和确实缺失。

非目标：

- 不把 TMDB 尚未更新的集数当作用户缺失。
- 不自动删除重复集。
- 不依赖文件数量简单判断完整度。

## 3. 功能范围

| 编号 | 功能 | 优先级 |
|---|---|---|
| EPS-001 | TMDB 季集基线 | Must |
| EPS-002 | 单集、集范围和季包解析 | Must |
| EPS-003 | 每集覆盖矩阵 | Must |
| EPS-004 | 缺失、重复、未知和未播出区分 | Must |
| EPS-005 | 特别篇处理 | Must |
| EPS-006 | 自动补集清单 | Must |
| EPS-007 | 完整度趋势和通知 | Should |

## 4. 状态定义

- 已拥有
- 多版本
- 缺失
- 未播出
- 无法识别
- 忽略
- 特别篇

季度完整度只统计已播出且未忽略的正式集。TMDB 数据更新时间必须展示。

## 5. 解析规则

- 支持 `S01E01`、`E01`、`S01E01-E03`、`EP01-03`。
- 支持中文第几季、第几集和更新至。
- 季包和全剧包通过文件清单检测后映射到具体集数。
- 一个文件覆盖多集时，为每集建立引用，不复制文件。
- 无季号的 E01 只能在上下文能确定季度时自动映射。
- 特别篇默认使用 Season 00，并允许人工覆盖。

## 6. 自动补集

- 用户从缺集矩阵选择缺失范围创建 REQ-007 订阅。
- 搜索只针对缺失集或缺失范围，不重复推送已拥有集。
- 季包包含已拥有和缺失集时，显示重叠风险并要求确认。
- 新文件整理后自动重新计算完整度。

## 7. 界面要求

- 剧集详情显示季度完整度和集数网格。
- 支持只看缺失、多版本、无法识别。
- 每集展示已有版本数、质量摘要和文件来源。
- 提供“订阅缺失集”“忽略此集”“修正映射”。

## 8. 验收标准

- 单集、多集、季包和全剧样本映射正确。
- 未播出集不计入缺失。
- 特别篇不污染正式季度完整度。
- 一个多集文件不会被计算成重复文件。
- 库存变化后完整度自动更新。
- 补集任务不会推送已拥有的精确重复资源。
- 无法识别项有明确中文原因和修正入口。

## 9. 分期建议

1. TMDB 基线与单集覆盖矩阵。
2. 多集、季包和特别篇。
3. 缺集订阅和自动补集。
4. 趋势、通知和人工映射规则。

## 10. 待确认项与建议默认值

| 决策项 | 默认值 |
|---|---|
| 完整度分母 | 已播出正式集 |
| 特别篇 | 单独展示，不影响正式季 |
| 无法识别 | 不算已拥有，也不自动补 |
| 多版本 | 算已拥有并标记重复 |
