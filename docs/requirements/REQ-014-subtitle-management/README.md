# REQ-014：字幕管理中心

| 字段 | 内容 |
|---|---|
| 版本 | V1.0 |
| 状态 | 开发中 |
| 优先级 | P1 |
| 依赖 | REQ-001、REQ-002、REQ-010 |

## 1. 一句话定义

识别、规范、同步和检查影视字幕，优先保证中文字幕与视频正确匹配，并维护 STRM 目录中的字幕一致性。

## 2. 目标与非目标

目标：

- 识别内封和外挂字幕的语言及类型。
- 规范字幕命名并关联正确视频或集数。
- 检查缺失中文字幕和重复字幕。
- 将字幕增量同步到 STRM 目录。

非目标：

- V1 不自动翻译字幕。
- 不上传用户字幕到第三方。
- 不根据文件名不确定信息静默覆盖字幕。
- 不承诺所有外部字幕源可用。

## 3. 功能范围

| 编号 | 功能 | 优先级 |
|---|---|---|
| SUBT-001 | 字幕文件发现和语言识别 | Must |
| SUBT-002 | 内封字幕检测摘要 | Must |
| SUBT-003 | 视频与字幕配对 | Must |
| SUBT-004 | 媒体服务器兼容命名 | Must |
| SUBT-005 | 缺失、重复和冲突检查 | Must |
| SUBT-006 | STRM 目录增量同步 | Must |
| SUBT-007 | 外部字幕源适配 | Should |
| SUBT-008 | 字幕预览和人工纠正 | Should |

## 4. 识别规则

- 支持 `srt`、`ass`、`ssa`、`sub`、`vtt`。
- 识别简体、繁体、双语、英文及其他语言。
- 识别 forced、SDH/HI、default 标记。
- 语言判断优先使用明确文件名标记，其次安全读取字幕元信息或抽样文本。
- 不把字幕正文写入日志或长期索引。
- 内封字幕只记录轨道数量、语言和标记，不提取完整内容。

## 5. 配对与命名

- 电影字幕关联 TMDB 电影和主视频。
- 剧集字幕必须匹配季号、集号或集范围。
- 多版本视频分别维护字幕关联，不跨版本静默复用。
- 建议命名：`video.zh-Hans.ass`、`video.zh-Hant.srt`、`video.en.forced.srt`。
- 同语言同类型多个字幕保留来源标记或进入冲突确认。
- 视频重命名或移动时字幕随 REQ-001 同步处理。

## 6. 缺失检查和补齐

- 可按质量策略定义“必须有简中/繁中/任意中文”。
- 内封字幕满足条件时不强制要求外挂字幕。
- 缺失项进入字幕待办，不影响视频入库。
- 外部字幕下载必须通过适配器、限流、校验和来源标记。
- 下载后先预览匹配分数，低置信度需要确认。

## 7. 界面要求

- 媒体详情展示内封和外挂字幕状态。
- 支持只看缺中文字幕、冲突、无法识别。
- 提供修改语言、配对视频、设为默认和忽略。
- STRM 同步页展示字幕同步结果和失败原因。

## 8. 验收标准

- 常见简中、繁中、双语、英文和 forced 命名识别正确。
- 电影、单集和多集字幕能关联正确视频。
- 视频移动或重命名后字幕保持关联。
- 未变化字幕不会重复下载或重写。
- 低置信度字幕不会自动覆盖现有字幕。
- 字幕正文和敏感路径不进入日志。
- Emby/Jellyfin/Plex 可识别生成的字幕命名。

## 9. 分期建议

1. 字幕发现、识别、配对和规范命名。
2. 缺失检查和 STRM 增量同步。
3. 人工纠正和外部字幕适配器。

## 10. 待确认项与建议默认值

| 决策项 | 默认值 |
|---|---|
| 中文字幕要求 | 无强制，质量策略可开启 |
| 115 已有字幕 | 优先 |
| 低置信度外部字幕 | 人工确认 |
| 字幕正文存储 | 不存储 |
