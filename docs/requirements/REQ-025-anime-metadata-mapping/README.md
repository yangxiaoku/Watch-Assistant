## 1. 一句话定义

为动漫建立作品、放送季度、绝对集数、标准季集、特别篇和文件之间的可解释映射，使搜索、整理、补集、字幕和合集在不同编号体系下仍能保持一致。

## 2. 背景与问题

现有整理和缺集能力以 TMDB 的季集结构为主，但动漫发布常见以下情况：

- 资源使用绝对集数，例如 `EP 25`，TMDB 使用 `S02E01`。
- 同一作品分割放送为多个 cour，不同元数据源的季度划分不同。
- OVA、OAD、SP、NCOP/NCED、总集篇和剧场版的归属不一致。
- 中文译名、日文原名、罗马音、英文名和简称差异明显。
- 一集可能有电视版、网络版、修正版或不同播放顺序。
- 合集包只写总集数或年份范围，无法直接映射标准季集。

仅使用文件名关键字或强制套用 TMDB Season 00 容易造成误移动、缺集误报和字幕错配，需要独立的动漫身份与集序映射层。

## 3. 产品目标

- 识别动漫作品及常见中、日、英、罗马音别名。
- 支持绝对集数与标准 `SxxExx` 双向映射。
- 表达分割放送、续作、特别篇、OVA/OAD 和剧场版关系。
- 将不同元数据来源和人工修正保存为有来源、有版本的映射。
- 为搜索、库存、完整度、命名和字幕提供统一集身份。
- 低置信度或来源冲突时进入人工确认，不自动移动文件。
- 人工确认可锁定，并在同系列后续文件中安全复用。

## 4. 非目标

- 不建设动漫播放、评论或社区产品。
- 不默认抓取未经许可的网站或绕过访问控制。
- 不强制用户使用某一个动漫元数据来源。
- 不把同一世界观的所有作品自动合并成同一剧集。
- 不因文件名出现 `OVA`、`SP` 就直接归入 Season 00。
- 不在 V1 自动处理帧级内容识别或视频指纹匹配。

## 5. 用户场景

### 5.1 绝对集数跨季度

资源名为 `作品名 - 25`，系统知道该作品第一季 24 集，因此把它映射为 `S02E01`，并展示映射来源和置信度。

### 5.2 分割放送

TMDB 将作品拆成两个季度，发布组按 `Part 1/Part 2` 或连续绝对集数发布。系统保持同一作品关系，同时为媒体服务器输出正确季集名称。

### 5.3 OVA 与总集篇

资源标记为 OVA，但多个候选特别篇标题相近。系统不自动归档，展示播出日期、时长和候选说明供用户确认。

### 5.4 合集包

一个目录包含正片、SP、NCOP 和 NCED。系统只把正片计入季度完整度，其他内容进入 extras 或待确认，不污染缺集统计。

## 7. 身份与映射模型

### 7.1 实体层级

- **作品**：用户认知中的动漫系列，使用内部稳定 ID。
- **发行条目**：TMDB 剧集、季度、电影或可选动漫数据源条目。
- **集身份**：作品中的逻辑集，包含绝对集数和可选标准季集号。
- **特别内容**：OVA、OAD、SP、总集篇、NCOP/NCED、PV 和其他 extras。
- **文件映射**：一个 115 文件与一个或多个逻辑集或特别内容的关联。

作品身份不能只依赖标题；至少需要外部 ID、人工确认或强关联证据。

### 7.2 映射记录

每条映射保存：

- 作品 ID、外部来源和外部条目 ID。
- 绝对集数、季度、集号和覆盖范围。
- 类型、标题、播出日期和可选时长。
- 映射来源、规则版本、置信度和证据。
- 是否人工确认、是否锁定和最后校验时间。

未知字段使用 `null`，不得用 `0`、Season 00 或猜测值代替。

## 8. 标题与作品匹配

候选标题包括：

- TMDB 当前语言标题和原名。
- 已验证来源提供的中文、日文、英文和罗马音标题。
- 用户确认别名、常用简称和发布组稳定命名。
- 分割季度的 `Part/Cour` 和续作标记。

规则：

- 标题规范化保留原始脚本，不把日文、罗马音强制合并成同一字符串。
- 同名不同年份、重制版、续作和剧场版必须使用年份、类型和外部 ID区分。
- 用户确认别名只在指定作品或系列范围生效。
- 搜索补充别名通过 REQ-005/REQ-023 的受控查询计划使用，不写入日志原文。

## 9. 集序映射规则

### 9.1 标准与绝对集数

- 支持 `S01E01`、`EP01`、`01`、`第01话` 和绝对集数范围。
- 映射必须基于已保存的季度起始偏移或逐集对应表。
- 季度集数变化、跳号或特别篇插入时使用逐集映射，不能只计算固定偏移。
- 一个文件覆盖多集时建立多个集引用，不复制文件。
- 映射规则变化后重算预览，已锁定文件不自动改变。

### 9.2 分割放送与顺序

支持以下顺序视图：

- TMDB 季集顺序。
- 绝对集数顺序。
- 播出日期顺序。
- 用户自定义顺序。

默认整理输出使用媒体库配置的标准季集顺序；搜索和识别可以同时接受绝对集数和 Part/Cour 表达。

## 10. 特别内容规则

- OVA、OAD 和 SP 先匹配明确外部条目、标题和日期，再考虑文件标记。
- 总集篇单独标记，不计入正片季度完整度。
- NCOP、NCED、PV、CM、采访和制作花絮归入 extras，不计为剧集。
- 剧场版默认作为电影实体，并可关联所属动漫作品或合集。
- 无法确定的特别内容进入待确认，不强制塞入 Season 00。
- 用户可以将特定特别篇设置为“计入收藏但不计入完整度”。

## 11. 置信度与冲突处理

置信度综合：标题、外部身份、季度/绝对集数、播出日期、时长摘要、目录上下文和已确认邻近文件。

必须降级人工确认的情况：

- 多个作品候选分差过小。
- 外部来源对季度或集数映射冲突。
- 绝对集数超出已知范围。
- 特别篇类型或归属不明确。
- 同一文件被映射到互不兼容的多个作品。
- 人工锁定结果与新自动规则冲突。

冲突页面必须展示各来源证据和将影响的命名、缺集、字幕及订阅结果。

## 12. 业务联动

- **REQ-001**：整理计划使用统一集身份生成目录和文件名。
- **REQ-005/023**：同时生成标题、季度、绝对集数和 Part/Cour 查询变体。
- **REQ-007**：订阅可以按作品、发行条目、季度或绝对集数范围追更。
- **REQ-010/011**：库存和完整度以逻辑集身份去重，不只比较文件名。
- **REQ-014**：字幕通过逻辑集和文件版本配对。
- **REQ-018**：体检发现映射冲突、越界和未知特别内容。
- **REQ-022**：剧场版和关联作品可以加入动漫系列合集，但不强制合并文件目录。

## 13. 命名与目录输出

推荐默认：

```text
作品目录：{title} ({year}) {tmdb-id}
季度目录：Season {season:02d}
正片文件：{title} - S{season:02d}E{episode:02d} - {episode-title}{technical-tags}.{ext}
特别内容：Specials/{title} - S00E{episode:02d} - {episode-title}.{ext}
附加内容：Extras/{extra-type}/{original-name}.{ext}
```

仅当 Season 00 映射已确认时使用 `S00E`；否则保留原文件并进入待确认。绝对集数可作为可选命名字段，但媒体服务器主编号仍使用已确认标准季集。

## 14. 管理界面与 API

管理界面提供：

- 动漫作品列表、外部身份和映射健康状态。
- 季度、绝对集数和特别内容对照表。
- 来源差异、未知文件、越界集数和待确认项。
- 单项确认、批量应用映射、锁定、解除锁定和回滚预览。
- 映射变化对整理、缺集、字幕和订阅的影响摘要。

API 只接受内部作品、映射、文件和外部条目 ID，不接受任意抓取 URL。批量变更使用版本号、幂等键和计划确认。

## 15. 数据、安全与日志

- 保存外部元数据快照、来源版本和使用许可摘要。
- 外部同步失败时保留最近成功快照，不清空映射。
- 人工确认和锁定属于业务审计，保存操作者、前后值、依据和影响范围。
- 遵循 REQ-004，日志记录映射数量、冲突类型和任务 ID，不记录完整文件名和路径。
- 可选元数据适配器遵循固定域名、限流、响应大小和严格 Schema 校验。

## 16. 验收标准

- 绝对集数跨季度样本能正确映射为标准季集，并可反向查询。
- 分割放送、续作和 Part/Cour 样本不会错误合并或重复计集。
- OVA、OAD、SP、总集篇、NCOP/NCED 和剧场版能区分处理。
- 未确认特别篇不会被强制命名为 Season 00。
- 多集文件只保存一份文件，并正确覆盖多个逻辑集。
- 人工锁定映射不会被外部同步或规则升级覆盖。
- 映射变化前可预览对整理、完整度、字幕和订阅的影响。
- 外部来源不可用时保留最近成功映射并显示数据新鲜度。
- 同名不同年份、重制版和剧场版不会仅凭标题误合并。
- 所有自动移动仍须满足 REQ-001 的置信度和计划保护。

## 17. 分期建议

1. 定义作品、发行条目、逻辑集和文件映射模型。
2. 支持 TMDB + 人工维护的绝对集数/季集映射。
3. 接入搜索、整理、库存和缺集流程。
4. 完善特别内容、字幕和剧场版关联。
5. 评估并接入一个合规动漫元数据来源。
6. 增加映射导入导出和复杂系列回归样本。

## 18. 风险与依赖

| 风险 | 缓解措施 |
|---|---|
| 不同来源集序冲突 | 来源证据、版本化映射和人工锁定 |
| 自动偏移造成批量错集 | 逐集映射、影响预览和低置信度确认 |
| 特别篇分类主观 | 独立类型、可忽略和用户覆盖 |
| 元数据来源不稳定 | 可选适配器、缓存快照和固定契约 |
| 规则变化破坏既有命名 | 已整理项锁定、版本比较和计划迁移 |

| 决策项 | 建议默认值 |
