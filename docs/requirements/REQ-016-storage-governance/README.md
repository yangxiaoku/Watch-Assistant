# REQ-016：存储空间与清理治理

| 字段 | 内容 |
|---|---|
| 版本 | V1.0 |
| 状态 | 待评审 |
| 优先级 | P2 |
| 依赖 | REQ-001、REQ-010、REQ-004 |

## 1. 一句话定义

统计 115 影视库空间占用，识别重复、隔离、过期和低价值内容，并通过可预览、可审批、可恢复的计划安全释放空间。

## 2. 目标与非目标

目标：

- 按媒体库、分类、地区和质量查看占用。
- 发现精确重复、旧版本、隔离过期和异常大文件。
- 支持配额和容量阈值告警。
- 所有清理先计划后执行。

非目标：

- 不默认永久删除。
- 不清理索引不完整或身份不确定的文件。
- 不把“大文件”自动视为低价值。
- 不处理配置范围外目录。

## 3. 功能范围

| 编号 | 功能 | 优先级 |
|---|---|---|
| STO-001 | 空间统计和趋势 | Must |
| STO-002 | 配额与阈值 | Must |
| STO-003 | 重复和旧版本候选 | Must |
| STO-004 | 隔离区保留策略 | Must |
| STO-005 | 清理计划与影响预览 | Must |
| STO-006 | 隔离、恢复和延迟删除 | Must |
| STO-007 | 计划审批和审计 | Must |
| STO-008 | 自动低风险治理 | Should |

## 4. 候选类型

- 精确重复文件。
- 已被更优版本替代且过隔离期的旧版本。
- 已取消任务留下的受管临时文件。
- 失效 STRM 和受管空目录由 REQ-002 处理，本需求只汇总。
- 长期未识别资源仅提示，不自动删除。
- 用户锁定、收藏、正在播放或有活动任务的资源不得进入自动清理。

## 5. 清理流程

1. 完整库存快照。
2. 生成候选和可释放空间估算。
3. 展示每项原因、身份、版本和保护状态。
4. 用户批准计划。
5. 默认移入隔离或回收站。
6. 保留期后再次生成永久删除计划。
7. 执行后更新库存、整理和 STRM 状态。

目录版本变化、库存不完整或计划过期时禁止执行。

## 6. 界面要求

- 仪表盘展示总占用、分类占用、增长趋势和阈值。
- 候选按预计释放空间、风险和原因筛选。
- 清理计划显示文件数、目录数、空间和不可逆动作。
- 支持隔离区恢复和保护资源。

## 7. 验收标准

- 空间统计与 115 样本目录误差在可解释范围内。
- 精确重复和版本重复不会混淆。
- 库存不完整时禁止清理。
- 活动任务、锁定资源和非受管文件零误删。
- 计划过期或目录变化后执行被拒绝。
- 隔离资源在保留期内可恢复。
- 永久删除默认关闭且 Agent 无权限执行。

## 8. 分期建议

1. 统计、趋势和阈值。
2. 重复与隔离候选。
3. 清理计划、审批和恢复。
4. 低风险自动治理和长期指标。

## 9. 待确认项与建议默认值

| 决策项 | 默认值 |
|---|---|
| 容量告警 | 80% WARNING，95% ERROR |
| 清理动作 | 移入隔离 |
| 隔离保留 | 7 天 |
| 永久删除 | 关闭 |
| 未识别资源 | 仅提示 |
