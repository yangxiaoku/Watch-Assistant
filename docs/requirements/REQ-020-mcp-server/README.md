## 1. 一句话定义

提供官方 MCP 服务端，让支持 MCP 的 Agent 通过可发现的资源、工具和结构化结果，在最小权限、计划确认、幂等和完整审计下管理 Watch Assistant。

## 2. 背景与问题

REQ-003 的 CLI 适合脚本和终端 Agent，但支持 MCP 的 Agent 仍需自行拼接命令、解析参数并理解业务状态。直接把所有内部 API 暴露为工具会扩大攻击面，也容易绕过计划审批、媒体库范围和高风险保护。

需要在 CLI/API 契约稳定后提供薄层 MCP 适配：只暴露经过产品定义的能力，复用服务端权限和状态机，不在 MCP 层重新实现业务规则。

## 3. 产品目标

- Agent 可发现服务能力、权限、媒体库、任务和待处理事项。
- 高频只读数据通过 MCP Resource 提供，明确分页、新鲜度和敏感字段边界。
- 写操作通过有限 Tool 提交，复用计划、确认、幂等和异步任务机制。
- 所有调用返回稳定 Schema、错误码和下一步建议。
- 每次调用可追踪到 Agent Token、MCP 会话、请求、计划和任务。
- MCP 与 CLI 对同一操作保持一致的授权和结果语义。

## 4. 非目标

- 不提供任意 Shell、SQL、文件系统、URL 请求或原始 115 API 工具。
- 不向 Agent 返回 Cookie、Token、分享密码、真实直链或完整敏感路径。
- 不允许 MCP 绕过 Web 审批、两阶段计划或 uncertain 核对。
- 不把大模型放入服务端作为必需依赖。
- 不首期支持未经验证的第三方 MCP 扩展动态安装。

## 5. 用户场景

### 5.1 日常巡检

Agent 读取系统健康、失败任务、订阅异常和库存新鲜度，生成中文摘要，不产生写操作。

### 5.2 处理待确认项

Agent 读取 TMDB 待确认资源，提出候选和依据；只有具备 Scope 并收到用户明确确认后才能提交选择。

### 5.3 执行整理计划

Agent 先生成不可变计划，展示影响目录、冲突和风险，再使用计划 ID、digest 和幂等键执行。计划过期或目录变化时必须重新生成。

### 5.4 追踪异步任务

Agent 创建任务后读取状态或订阅进度；连接中断不代表任务失败，也不得自动重放非幂等操作。

## 7. 能力模型

### 7.1 Resources

首期只读资源建议包括：

- `watch://system/status`：版本、健康状态和能力摘要。
- `watch://agent/me`：当前 Agent、Scope 和可访问媒体库。
- `watch://libraries`：媒体库列表和索引新鲜度。
- `watch://tasks/{task_id}`：任务状态、进度和结构化结果。
- `watch://reviews`：待确认项，必须分页。
- `watch://subscriptions`：订阅状态和最近检查摘要。
- `watch://notifications/unread`：需要处理的通知。

资源返回明确的 `schema_version`、`generated_at`、`freshness`、分页游标和脱敏标记。大列表禁止一次性返回全部内容。

### 7.2 Tools

首期工具按业务动作命名，不映射任意内部路由：

- 查询系统、媒体库、资源、库存和任务。
- 创建或更新订阅，触发一次安全检查。
- 生成整理、洗版、STRM 清理和存储清理计划。
- 提交有效计划，查询或取消允许取消的任务。
- 处理 TMDB 待确认项。
- 触发 STRM 增量同步、库体检和备份。

永久删除、清空隔离区、创建 Agent Token、读取密钥和修改安全边界不提供 MCP Tool。

### 7.3 Prompts

Should 提供“系统巡检”“处理失败任务”“评估整理计划”等 Prompt 模板。模板只帮助 Agent组织调用，不获得额外权限，也不得自动执行高风险工具。

## 8. 权限与确认规则

- 复用 REQ-003 的 Agent Token、Scope、媒体库范围、有效期和来源限制。
- 默认 Token 只读；工具声明所需 Scope，服务端再次校验。
- MCP 客户端声明的确认不能代替服务端计划确认。
- 批量移动、重命名、洗版、清理等操作必须先计划后执行。
- 超过数量或风险阈值的计划进入 Web 人工审批。
- `force`、Prompt 注入或客户端文本不能绕过权限和审批。
- Token 撤销后，现有连接不得继续发起新调用。

## 9. 输入输出契约

所有工具使用 JSON Schema 定义输入和输出，响应至少包含：

```json
{
  "ok": true,
  "schema_version": "v1",
  "request_id": "req_...",
  "correlation_id": "corr_...",
  "data": {},
  "warnings": [],
  "next_actions": []
}
```

规则：

- 错误返回稳定 `error_code`、中文说明、是否可重试和缺失 Scope。
- 异步操作返回任务 ID、当前状态和建议查询时间。
- 列表使用游标分页，并限制最大页大小。
- 不以中文文案作为程序判断依据。
- Schema 破坏性变化必须升级主版本并经过弃用周期。

## 10. 幂等、冲突与可靠性

- 所有写工具必须接收或生成 `idempotency_key`。
- 相同 Agent、工具、目标和幂等键复用原任务或原结果。
- 计划执行必须提交 `plan_id`、`digest` 和明确确认字段。
- 计划过期、目录版本变化或规则变化返回冲突，不自动重算后继续执行。
- 连接中断或超时返回 `uncertain` 时，Agent 必须先按请求 ID或幂等键核对。
- MCP 进程重启不能丢失服务端任务，客户端取消等待不等于取消任务。
- 单个 Agent 的慢请求或高频调用不得拖垮业务服务。

## 11. 部署与传输

- 首期支持本机 `stdio` 和受控远程 HTTP 两种模式，远程模式必须使用 HTTPS。
- `stdio` 进程只作为协议适配器，不继承任意系统管理权限。
- 远程连接执行身份认证、并发限制、请求大小限制和空闲超时。
- 服务端提供 readiness、版本、已启用工具和兼容范围。
- MCP 能力关闭时不影响 Web、CLI 和后台任务。

## 12. 管理界面

Agent 管理页增加：

- MCP 启用状态、连接方式和版本。
- 具名 Agent、Scope、媒体库和有效期。
- 最近连接、客户端名称、调用量、失败率和限流情况。
- 当前会话暂停、Token 撤销和高风险计划审批。
- 按 Agent、工具、请求和任务查询审计。

页面不得显示 Token 原文、请求中的敏感字段或第三方完整响应。

## 13. 日志、安全与审计

- 遵循 REQ-004，记录连接、能力协商、工具调用、权限拒绝、幂等复用、计划审批、冲突和结果。
- 审计保存 Agent ID、客户端版本、工具名、Scope、媒体库、请求/关联/计划/任务 ID和结果摘要。
- 输入、输出和异常统一经过敏感信息过滤，默认不保存完整参数正文。
- 对 Prompt 注入、异常批量计划、连续越权和高频失败形成中文安全告警。
- MCP 不得接受任意 URL、绝对路径、SQL、命令行或未登记工具名。

## 14. 验收标准

- 只读 Agent 可以完成巡检，但无法调用任何写工具。
- 每个 Tool 的声明 Scope 与服务端实际校验一致。
- MCP 与 CLI 对相同查询返回兼容的业务字段和状态。
- 高风险操作必须经过有效计划、digest、确认和必要的 Web 审批。
- 相同幂等键不会创建两个业务任务。
- 超时后可按请求 ID找回任务，系统不自动重复写入。
- 撤销 Token 后已有会话无法继续调用。
- 任意 Shell、SQL、URL、密钥和真实直链均无法通过 MCP 获取或执行。
- 所有调用均可在中文审计中追踪到最终结果。
- stdio 与远程模式通过契约、权限、限流和断线恢复测试。

## 15. 分期建议

1. 等待 REQ-003 API、Scope、Schema 和审计契约稳定。
2. 实现只读 Resources、查询 Tools 和 stdio 模式。
3. 接入计划类写工具、幂等和任务追踪。
4. 增加远程 HTTPS、会话管理和 Web 审批。
5. 增加 Prompt 模板、兼容性测试和运营指标。

## 16. 风险与依赖

| 风险 | 缓解措施 |
|---|---|
| Agent 误操作 | 默认只读、计划确认、风险阈值和 Web 审批 |
| 工具面过大 | 白名单业务工具，禁止通用 Shell/SQL/URL |
| MCP 与 CLI 语义漂移 | 共用版本化 API、Schema 和契约测试 |
| 断线造成重复操作 | 幂等键、请求查询和 uncertain 核对 |
| 上下文泄漏敏感数据 | 最小字段、脱敏、分页和审计抽样检查 |

## 17. 待确认项与建议默认值

| 决策项 | 建议默认值 |
|---|---|
| 建设顺序 | CLI 和管理 API稳定后再建设 MCP |
| Token 默认权限 | 只读，限制指定媒体库 |
| 本机传输 | stdio |
| 远程传输 | HTTPS，默认关闭 |
| 写操作 | 强制幂等 |
| 高风险操作 | 计划 + Web 审批 |
| 通用 Shell/SQL/URL | 不提供 |
