# 更新日志：115 真实操作开关（2026-07-29）

## 新增

- 新增独立的 `ORGANIZATION_WRITE_ENABLED`，控制真实 115 整理、移动和重命名写入；整理计划和操作排队仍可单独保持开启。
- 新增 `ORGANIZATION_WRITE_CONTRACT_VERIFIED`，未完成真实写入契约验收时即使误开写入开关也不会启动生产 worker。
- 新增 `PERMANENT_DELETE_ENABLED`，永久删除必须同时经过真实写入开关、权限、对象名称确认、完整扫描前置条件和远端写后验证。
- 新增 `PERMANENT_DELETE_CONTRACT_VERIFIED`，删除语义契约未冻结前始终拒绝真实删除。
- 新增 STRM 全量生成开关 `STRM_FULL_ENABLED`，基于完整且最新的媒体库扫描生成受管 manifest 和本地 `.strm` 文件。
- 新增 STRM 增量、清理、播放及播放契约开关：`STRM_INCREMENTAL_ENABLED`、`STRM_CLEANUP_ENABLED`、`STRM_PLAYBACK_ENABLED`、`STRM_PLAYBACK_CONTRACT_VERIFIED`。
- 新增基于完整扫描差异的 STRM 增量对账和失效清理接口；清理只会删除内容仍与系统生成模板一致的受管 `.strm` 文件。
- 健康接口新增各项开关状态，便于部署后确认实际生效配置。

## 安全与兼容

- 所有新增开关默认关闭，部署示例也保持关闭。
- 删除遇到超时、观察不完整或写后状态不一致时返回 `uncertain`，不会自动重复提交。
- C03 仍固定 `VERIFIED_FS_FILES_PAGE_SIZE=1`，`errno=990009` 继续按 3 秒重试。
- 本版本没有打开生产真实写入、永久删除或未经契约验证的 STRM 播放。
- 动态播放开关即使配置为 `true` 也不会报告为可用，直到真实直链、鉴权以及 HEAD/GET/Range 契约完成验收。
- 设置页会显示整理、移动/重命名、删除和 STRM 各项的实际有效能力状态。
