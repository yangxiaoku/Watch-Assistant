## 一、端到端体检发现的问题与修复

### 1. 订阅创建 409(生产 schema 漂移,迁移 075)
- **根因**:生产库早于当前仓库谱系,`subscriptions` 表残留 `identity_key`/`title`(NOT NULL、无默认值),当前模型已不定义;新 INSERT 不提供这两列 → NOT NULL 违反被误报为 `subscription_exists`,任何新订阅都 409。
- **修复**:迁移 075 按当前模型重建订阅表(快照子表 → DROP → 重建 → 恢复),旧数据/observations/checks 全保留。

### 2. 推送任务面板(失败 + 无限转圈)
- **失败根因**:org-source 库最新扫描失败(`gateway_error`)→ 库存守卫 `inventory_index_incomplete` 拦下所有推送。
- **转圈根因**:submitted 任务无自动推进路径(claim_next 只认 QUEUED、claim_expired 只认 SUBMITTING),前端把 submitted 渲染成无限转圈。
- **修复**:恢复扫描解锁守卫;适配器映射 115 数字状态码(0/1/2/3);新增 `claim_submitted` + watcher 自动只读轮询推进;前端 submitted 停止假转圈、改稳定图标与"已提交/下载中"文案;2s 空轮询移除。

### 3. STRM 清理与增量同步
- **清理**:`STRM_CLEANUP_ENABLED=false` 配置关闭 → 开启 + 重启。
- **增量**:dirty worker 只在 p115 cookie 变更回调里启动,全新重启从不启动 → 启动时补 `apply_dirty_runtime`,队列恢复消费;静默吞异常补日志。

### 4. 媒体库页面
- 工作台重构为标签页(概览/清理/文件),新增用途说明,移除永远"未知"的修改时间列。

### 5. 自动整理

### 6. 安全

## 二、新增功能

### 1. 115 网盘自动签到
- 每日按配置时间(默认 00:05)自动调用 proapi 积分签到接口。
- 默认关闭,设置页可开启/关闭(运行时生效,无需重启);`is_sign_today` 幂等(同日只签一次)。
- 成功/失败都推送通知(签到事件绕过静默时段)。
